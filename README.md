# ATELIER.UI — Quiet Luxury Component System

A modular, precision-engineered UI component playground adhering strictly to the **Quiet Luxury** design standards:
- Tone-layered surfaces (True AMOLED `#101010` & Soft Off-White `#f9f9f9`)
- Hairline borders (`border-white/[0.07]`)
- Distinctive display typography (Syne 800)
- Phosphor Icons (zero emojis, zero ad-hoc SVGs)
- Ultra-narrow & foldable device responsiveness (down to 280px Samsung Galaxy Z Fold & iPhone 13 mini)
